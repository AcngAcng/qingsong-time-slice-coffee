# Time Slice Coffee Visual Design System

## Direction

Warm minimal coffee brand + sharp data label system.

The deck should feel like a coffee brand launching a new category: an information consumer product for the AI age. It should not feel like an AI SaaS dashboard, startup template, or generic data product deck.

## Mood

Premium, playful, thoughtful, slightly local.

The visual world combines:

- Coffee cup
- Order menu
- Pickup label
- Receipt
- Raw signal cards
- Barcode-like data labels
- Persona tags
- Density tags
- Served Hot / Served Iced tags
- Information shelves

## Palette

- Coffee cream: `#F8F0E6`
- Warm paper: `#FFF9EF`
- Oat gray: `#EEE4D6`
- Espresso brown / black: `#15100D`
- Black text: `#241913`
- Muted roast red: `#B5482E`
- Deep roast red: `#8F321F`
- Subtle signal cyan: `#3BA7A1`
- Warm metadata gray: `#8C8175`

Color rules:

- Use cream and warm paper as the primary coffee-brand base.
- Use espresso for titles, dark slides, and label headers.
- Use muted roast red as the main accent for slogans, active tags, and label strips.
- Use cyan sparingly as a signal accent, never as a dominant AI-gradient color.

## Typography

Title feel:

- Large, clean, editorial.
- English claim titles can use a refined serif feel.
- Chinese support titles should be readable and calm.

Body feel:

- Clear sans-serif body text.
- Avoid dense paragraphs on slides.
- Keep one core sentence per slide.

Data label feel:

- Use small mono-style labels for shelf names, label numbers, signal fields, and metadata.
- Data text should feel like packaging, receipts, and pickup labels, not a dashboard table.

## Layout Rule

Each slide must have:

1. One strong title.
2. One core sentence.
3. One visual metaphor.

Avoid:

- Generic blue-purple AI gradients.
- Dashboard-heavy SaaS look.
- Too many bullet points.
- Corporate startup template feeling.
- Repeated card-grid slide rhythm.

## Shape Language

Use crisp rectangles, receipt strips, hairline rules, sticker blocks, and menu-board panels.

Avoid default rounded cards unless the shape is clearly behaving like a physical label or tag.

## Data Label System

A Time Slice label is the visible product system, not decoration. It should make this framework readable:

`Raw Signal → Extracted Slice → Persona → Density → Served Mode → Brew Result → Label / Pick Up`

A reusable Time Slice label should include:

- Top espresso header band.
- Small mono metadata fields.
- A label number such as `TS-001`.
- `SHELF`
- `RAW SIGNAL`
- `EXTRACTED SLICE`
- `PERSONA`
- `DENSITY`
- `SERVED`
- `BREW RESULT`
- `TAKEAWAY`
- Barcode-like marks.
- One small roast-red accent strip.

The label should look printable, attachable, and portable.

## Slide Rhythm

1. Cover: pickup product moment.
2. Problem: information pressure scene.
3. Insight: consumption evolution.
4. Product: order menu.
5. Workflow: raw signal to brew result.
6. Demo: one signal branching into six persona values.
7. Technology: stable demo today, real-time future tomorrow.
8. Closing: pickup / label mood visual.

## Image Policy

Use generated images only for selected visual assets:

- Cover image.
- Coffee cup with data label concept.
- Raw signal to brew result metaphor.
- Pickup / label mood visual.

Do not rasterize the entire deck. Titles, body text, labels, diagrams, arrows, and simple shapes remain editable in PowerPoint.
