# Signal Quality Standard

Time Slice Coffee 不是热点收集，而是信息提炼。

每条 signal 进入正式库之前，必须先能回答一个问题：这条信息背后，世界的哪个流程、能力、关系、成本或日常决策正在变化？

## 1. 总原则

每条 signal 必须满足：

- 有具体事件。
- 有明确主体。
- 有来源感。
- 能看出背后的变化。
- 能被提炼成一句 Time Slice 标签。
- 不是鸡汤。
- 不是泛泛趋势。
- 不是“有人用 AI 做了个小工具”这种轻内容。

不合格 signal 的常见特征：

- 只有“AI 正在改变某某”这种趋势判断，没有具体事件。
- 主体模糊，例如“有人”“网友”“一家公司”但没有可追踪来源。
- 只是工具发布，但看不出流程、成本、采购、生活决策或能力边界的变化。
- 只是营销稿、融资通稿或产品宣传，没有可提炼的信息结构。
- 标签潜力只能写成“机会可能在这里”“值得继续关注”“今天学会这一点”。

## 2. 每个 Shelf 的入库标准

### AI Frontier / AI 前沿

关注 AI 能力边界变化。

收：

- agent
- 模型能力
- 多模态
- memory
- tool use
- AI safety
- computer use
- on-device AI

不收：

- 普通产品营销。
- 泛泛模型发布。
- 没有能力变化的新闻。
- 只说“模型更强了”但没有新能力、新边界或新风险的内容。

合格例子：

- Agent 从聊天回答走向真实电脑操作。
- Agent 记忆从上下文窗口走向持久化 memory。
- 多模态感知从摄像头走向 WiFi、设备端或现实环境。

### Build & Workflow / 构建工作流

关注做事方式和工作流变化。

收：

- 开发者工具
- MCP
- repo
- PR
- testing
- deployment
- review
- incident response
- workflow automation

不收：

- 单纯工具发布。
- 没有流程变化的产品更新。
- 只是“某 IDE 加了 AI 功能”，但看不出构建、测试、审查、部署或协作方式变化。

合格例子：

- Cursor 读取真实数据库 schema 后生成代码。
- Copilot review 自动拉取 Figma 设计上下文。
- Agent 直接触发部署预览并检查结果。

### Design & Creation / 设计创作

关注创作流程、交付标准、版权证明、客户验收变化。

收：

- Figma
- Adobe
- Canva
- AI video
- storyboard
- provenance
- design system
- client review

不收：

- 单纯“生成效果很惊艳”的内容。
- 没有交付、证明、审查、协作或标准变化的图片和视频生成展示。
- 只展示作品，不说明创作流程如何改变。

合格例子：

- AI video 从一句 prompt 走向 storyboard-first 流程。
- Firefly 在交付文件里加入 provenance 证明。
- Figma Agent 在画布内执行批量修改并遵守设计系统。

### Market & Capital / 市场资本

关注钱、资源、成本、采购、收入、资本流向、商业模式。

收：

- 投资判断
- 融资结构
- 企业采购
- ARR / revenue quality
- API price war
- inference cost
- GPU / power / data center 对商业判断的影响

不收：

- 泛泛 AI 技术新闻。
- 普通宏观新闻。
- 只说“AI 很火”的内容。
- 和采购、收入、成本、融资、资本配置无关的能力新闻。

合格例子：

- 电力成为 AI data center capex 的硬约束。
- 企业采购从一次性预算转向 FinOps 成本控制。
- API 价格战改变模型公司收入质量判断。

### Self Upgrade / 自我升级

关注个人能力证明、职业变化、学习验证、作品集和工作流迁移。

收：

- 招聘标准变化
- 面试变化
- AI workflow 作品集
- 个人 agent workflow
- 学习结果验证

不收：

- 鸡汤式成长建议。
- 普通课程推荐。
- 没有真实职业筛选、能力证明或学习验证变化的个人效率内容。

合格例子：

- 面试新增 Cursor / Claude Code 实时配对编程。
- 作品集从静态代码转向可运行 Agent workflow。
- 课程考核从理论报告转向可交付 Agent 项目。

### Life Signals / 生活信号

关注 AI 如何改变真实日常决策。

收：

- 购物
- 家庭
- 健康
- 教育
- 通勤
- 城市服务
- 消费决策
- 隐私信任
- 普通用户实际使用 AI 的场景

不收：

- 轻飘的小工具。
- 泛泛“AI 改变生活”。
- 没有真实决策变化的内容。
- 只是“用户让 AI 推荐一下”的通用聊天案例。

合格例子：

- AI 虚拟试穿影响下单和退货。
- AI 辅助家庭健康、服药和预约管理。
- AI 辅助房产、装修、教育、通勤等高频或高成本生活决策。

## 3. 评分标准

每条 signal 以 1-5 分打分。

### 真实性

是否有具体事件、主体和来源。

- 5: 有明确主体、事件、来源或可追踪上下文。
- 4: 主体和事件清楚，但来源需要进一步核验。
- 3: 事件方向成立，但主体或来源感偏弱。
- 2: 像概念拼接或泛案例。
- 1: 基本没有真实事件感。

### 货架相关性

是否真的属于当前 shelf。

- 5: 与 shelf 标准高度匹配。
- 4: 匹配，但可能与另一个 shelf 有交叉。
- 3: 可勉强归入，但不是最佳 shelf。
- 2: 应该换 shelf。
- 1: 不属于当前 shelf。

### 专业度

是否满足该 shelf 的专业期待。

- 5: 有明确专业判断维度。
- 4: 专业方向清楚，但还可补更强来源或数据。
- 3: 可用，但偏浅。
- 2: 太泛或太轻。
- 1: 像普通热点或工具推荐。

### 可提炼性

是否能提炼出结构性变化。

- 5: 很容易提炼成“从 A 到 B”或“X 正在进入 Y”。
- 4: 可提炼，但需要编辑压缩。
- 3: 有变化，但表达需要重写。
- 2: 只能提炼成泛泛趋势。
- 1: 难以提炼。

### 标签潜力

是否能变成一句有价值的 Time Slice 标签。

- 5: labelPotential 已接近可用。
- 4: 稍作压缩即可用。
- 3: 需要重写，但信息本身有潜力。
- 2: 容易变成空泛判断。
- 1: 不适合做标签。

## 4. 入库判断

- 平均分低于 3 的 signal 不应进入正式库。
- 任一关键项低于 3 时，应标记为“删除”“换 shelf”或“需要重写”。
- Market & Capital 必须至少满足一个硬条件：投资、融资、采购、收入、成本、资本流向、商业模式。
- Life Signals 必须能说明一个真实日常决策被改变，不能只是“AI 推荐一下”。
